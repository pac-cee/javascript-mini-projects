# React Learning Path

This project is designed to help you learn React from beginner to advanced level through practical, real-world examples. Each section builds upon the previous one, introducing new concepts progressively.

## Project Structure

```
react-learning-path/
├── src/
│   ├── components/
│   │   ├── basics/
│   │   ├── intermediate/
│   │   └── advanced/
│   ├── hooks/
│   ├── context/
│   ├── redux/
│   └── App.js
├── public/
└── package.json
```

## Learning Path

### 1. Basics
- Components and Props
- State Management
- Event Handling
- Conditional Rendering
- Lists and Keys

### 2. Intermediate
- React Hooks (useState, useEffect, useRef)
- Forms and Controlled Components
- Component Lifecycle
- Error Boundaries
- React Router

### 3. Advanced
- Context API
- Redux State Management
- Custom Hooks
- Performance Optimization
- Testing
- Authentication
- API Integration

## Getting Started

1. Clone this repository
2. Install dependencies:
```bash
npm install
```
3. Start the development server:
```bash
npm start
```

## Available Scripts

- `npm start`: Runs the app in development mode
- `npm test`: Launches the test runner
- `npm run build`: Builds the app for production
- `npm run eject`: Ejects from Create React App

## Dependencies

- React 18.x
- React Router 6.x
- Redux Toolkit
- Axios
- Material-UI
- React Testing Library
